Manrope and Newsreader are bundled locally for Vox's reading and display typography.
The WOFF2 files contain variable upright fonts with Latin and extended Latin subsets.
Traditional Chinese uses the device's PingFang TC or Noto Sans TC font.

Sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope),
[Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader), downloaded
from Google Fonts on 2026-10-11. Each font's SIL Open Font License is included
alongside its files as `manrope-OFL.txt` and `newsreader-OFL.txt`.
