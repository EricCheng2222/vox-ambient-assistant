Newsreader is bundled locally for Vox's display headings. Body text uses the native
system font (San Francisco on Apple devices); it is supplied by the operating system.
Traditional Chinese uses the device's native Chinese font, with PingFang TC and
Noto Sans TC fallbacks.

The WOFF2 files contain variable upright Newsreader with Latin and extended Latin
subsets. Source: [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader),
downloaded from Google Fonts on 2026-10-11. Its SIL Open Font License is included
as `newsreader-OFL.txt`.
